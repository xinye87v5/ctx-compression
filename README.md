# ctx-compression · 上下文压缩的实测方法论

> 我们用**可复现的测量**去回答一个问题：
> **LLM agent 的上下文压缩，到底丢了什么、丢在哪一步、以及能不能不丢。**
>
> 所有结论都附带条件、样本量与反例；**被推翻的结论和成立的结论一样，都留在这份文档集里**。

---

## 一句话结论

> **压缩里最不可再生的信息是「人说过什么」——而现有机制把它交给模型自觉。**
>
> 实测：官方压缩指令要求"逐字引用用户原话"，实际逐字存活率只有 **7%**；
> 短发言（"同意"、"可以"这类）在摘要里几乎不留痕，**而它们指向什么完全丢失**。
>
> 这一条不靠提示词解决。我们把"用户发言逐字 + 所指锚"改由 **harness 用代码注入**，
> 主指标从 **≈0% 提到 78–100%**（见 `docs/04-interventions.md`）。

---

## 这个项目解决什么

长会话的 agent 每隔一段时间必须压缩历史。压缩是**不可逆**的：原始事件还在磁盘上，
但**模型再也看不到它**，除非有召回通道——而实测 19 次压缩事务里 **recall 类工具调用 0 次**。

于是问题的正确形式不是"摘要写得好不好"，而是：

| | 工作台型历史 | 进度型历史 |
|---|---|---|
| 上下文是 | **工作台本身** | **进度指针** |
| 丢一段 | 信息没了，要重新抠 50 分钟 | 无所谓，磁盘上有 |
| 该不该压 | **不该** | **该，而且可以很激进** |

现有机制对这两种情况的处理**完全相同**。

**核心命题**：压缩的第一性决策不是"保留多少"，而是"这段历史是工作台还是进度"。

形式上这等价于用**任务条件信息量 `I*(Q)`** 替代固定阈值，并用蓝图作为查询 `Q` 的廉价代理
（见 `docs/01-problem.md`）。

## 几条不可交易的原则

| # | 原则 | 为什么 |
|---|---|---|
| **P1** | 压缩质量只能由**会话的后续行为**评判，不能靠摘要自评 | 自评等于让被考的人出卷 |
| **P2** | **可逆性优先于任何打分技巧** | 可逆性同时是一切测量的前提 |
| **P3** | 条件化在**任务结构**上，而不只是 token 压力 | 否则要付 query-agnostic 的代价 |
| **P4** | 自适应只允许调**预算**与**可丢类目**，不允许改**硬事实定义** | 防止系统自我说服 |
| **P5** | 按「**丢了能不能重建**」分类，而不是按「统计上重不重要」 | 实测压缩器的先验方向与信息价值**倒挂** |

## 理论依据

**主文献**：Colaco & Lahjouji (2026), *What to Keep, What to Forget: A Rate–Distortion View of
Memory Compaction in LLMs and Agents*, [arXiv:2607.08032](https://arxiv.org/abs/2607.08032)。

三条直接决定本设计的结论：

1. **可达到的压缩比 ∝ 1 / I\*(Q)** —— 可压缩性由任务决定。同一 KV 驱逐器"在摘要任务上近无损，**在检索任务上崩溃**"。
2. **query-agnostic 要付 `H(Q)` 的代价** —— 差距有精确表达式，是可定价的损失。
3. **三个一等属性**：可逆性、查询条件化、保真剖面。文献断言 *"reversibility usually matters more than any scoring trick"* —— 我们的实测支持这一条。

语言学的补充（可及性理论、共同背景、话题-述题、关联理论）回答另一半：
压缩的正确定性形式不是"把内容缩写"，而是**"把内容替换为一个足够可及的回指形式"**，
而回指的可及性必须由外置的蓝图保证 —— 这直接推出了"所指锚"的设计。

## 关于数据

本仓库是**方法论**的发布集。**原始会话数据不在其中**：
逐字用户发言、压缩产生的 checkpoint 全文、以及从真实会话抽取的中间产物，
都含个人与业务内容，不随本仓库发布。工具链实现同理。

示例中的私人项目名、作品名与个人文档名已做匿名替换。
每篇文档的数字都标明了**条件与样本量**，方法论可直接搬到自己的语料上复用。

## 状态与边界

- **实测环境**：DSH harness（cordis 插件体系），会话来自真实使用而非构造的基准集。
- **样本量普遍偏小**：多数结论 n 在 2–10 之间，已逐条标注。**不要把 n=1–3 的读数当定论。**
- **有些结论明确没通过预注册**（压力与抱怨率的关联、单次压缩的代价点估计）——
  它们被标为"探索性、未确认"，见 `docs/05-claims.md`。
- **本项目自己犯过的错**同样记录在案：三类测量缺陷、四次指标失效、两条被撤回的结论。
